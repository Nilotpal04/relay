# Relay

**Capture. Inspect. Replay.**

Relay is a real-time webhook debugging platform for developers.

It provides temporary webhook endpoints, request inspection,
live event updates, and secure request replay.

## Planned Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- Real-time communication: WebSockets
- Background jobs: Redis and a Python worker
- Infrastructure: Docker Compose
- Testing: pytest and frontend testing tools

## Project Structure

- `frontend/` — Web application
- `backend/` — API and background worker
- `infra/` — Local infrastructure and deployment configuration
- `docs/` — Architecture and engineering documentation
